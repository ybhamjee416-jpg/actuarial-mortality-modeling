# Actuarial Mortality Modeling Pipeline

## Overview
An R-based quantitative model developed to analyze mortality data and evaluate financial risk. This project demonstrates core actuarial modeling techniques, data cleaning, and statistical visualization.

## Key Features
* Data preprocessing and cleaning of raw demographic/mortality datasets.
* Application of actuarial graduation and survival analysis techniques in R.
* Generation of automated risk projection plots and summary reports.

## Tech Stack
* **Language:** R
* **Libraries:** tidyverse, ggplot2 (or whatever packages you used)
